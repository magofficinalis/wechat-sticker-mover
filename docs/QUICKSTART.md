# 表情搬运助手：第一次使用教程

这份教程面向第一次使用工具的人。跟着完成一次设置后，以后通常只需要打开微信和模拟器，再点“导入微信新增表情”。

**你需要 Windows 电脑。手机可以是安卓，也可以是 iPhone。** 程序操作的是电脑模拟器里的小红书，手机用于确认收藏是否同步。

## 先准备好这四样

| 需要什么 | 用来做什么 |
| --- | --- |
| Windows 电脑上的表情搬运助手 | 运行本工具 |
| 已登录的电脑版微信 | 读取你自己添加的表情；如果只导入电脑图片，可以不用这个来源 |
| 雷电 9 模拟器及其中的小红书 | 接收表情、执行收藏 |
| 手机上的小红书 | 核对收藏和动画，需与模拟器登录同一账号 |

**版本先核对：** 微信读取沿用对 4.1.13.12、4.1.13.65、4.1.15.13 的适配，本项目已实测 4.1.15.13；模拟器小红书内置适配为 **9.33.4、横屏 16:9**。其他版本不能直接当作已经兼容。完整限制见 [README](../README.md#兼容性)。

## 第一步：下载、安装并打开工具

1. 打开 [GitHub 发布页](https://github.com/magofficinalis/wechat-sticker-mover/releases/latest)。
2. 找到页面的 **Assets**，下载 Windows 发布包或安装程序。不要把 `Source code` 当安装包。
3. 如果下载到的是压缩包，右键点击它，选择 **“全部解压缩”**。等解压完成，再打开解压出来的文件夹。
4. 双击里面的 `StickerImporter-版本号-Setup.exe`，按安装向导操作。
5. 从 Windows 开始菜单打开 **“表情搬运助手”**。如果创建了桌面快捷方式，也可以双击快捷方式。

0.8.1 安装包尚无代码签名，Windows 可能显示未知发布者。先核对下载来源与发布页校验值，不要为此关闭系统防护。

如果下载的是免安装版，请保留主程序旁的 `_internal` 文件夹。不能只把 EXE 单独拖到桌面。

## 第二步：把模拟器准备好

1. 安装并打开雷电 9。
2. 打开雷电的设置，在 **“其他设置”** 中找到 **“ADB 调试”**，选择 **“本地连接”**。
3. 保存设置，按提示重启模拟器。
4. 在模拟器里安装小红书，自行完成登录。
5. 核对模拟器的小红书账号与手机相同。不要只看头像，确认账号信息一致。
6. 将模拟器设置为 **横屏 16:9**，使用已适配的小红书版本。

回到搬运助手：

1. 点击顶部 **“设置与帮助”**。
2. 点击 **“1 连接模拟器”**。
3. 点击 **“查找模拟器”**。
4. 在设备列表中选择正在使用的模拟器。如果开了多个实例，要确认选择正确。

找不到设备时，先检查模拟器是否已经启动、ADB 是否开启并重启，再到高级选项检查 ADB 路径。反复点击“导入”不能解决设备连接问题。

## 第三步：选择微信来源与目标账号

### 如果要从微信收藏直接搬运

1. 打开并登录 **电脑版微信**。
2. 到微信聊天窗口的表情面板，确认能看到自己添加的表情。
3. 在搬运助手点击 **“设置与帮助 → 2 微信和账号”**。
4. 点击 **“查找微信”**，从下拉列表选择自己的微信来源。
5. 如果有多个来源，请选择目前登录账号对应的目录。

自动查找没有结果时，点击 **“手动选择”**，找到下面结构中的 `emoticon.db`：

```text
xwechat_files
└─ 你的微信账号目录
   └─ db_storage
      └─ emoticon
         └─ emoticon.db  ← 选择这个文件
```

**这里选文件，不是选普通图片文件夹。** 路径能显示，仅表示文件已被选择；微信版本不兼容或来源不正确时，后续仍可能无法读取。

### 填写小红书账号标签

在“小红书账号标签”里填一个自己看得懂、以后能保持不变的名称，例如 **“我的小红书”**。这是工具在电脑里区分任务的名称，不是小红书密码，也不会替你登录。

确认模拟器已登录正确账号后，勾选下面的账号确认。换微信来源、模拟器或账号后，需要重新核对并勾选。

### 如果只想导入电脑里的图片

微信数据库读取不是必需步骤。仍然需要连接模拟器、填写目标账号标签并确认目标账号，然后到 **“开始搬运 → 从文件夹添加”** 添加图片，按程序提示完成首次验证。

## 第四步：打开小红书收藏表情面板

在模拟器里操作：

1. 打开小红书并进入聊天窗口。
2. 打开聊天输入框旁的表情面板。
3. 切换到 **“已添加的表情”** 或收藏表情区域。
4. 确认能看到用于添加表情的 **加号**。
5. 保持这个页面不动，再回到搬运助手操作。

这里指的是**聊天表情收藏面板**，不是首页发布笔记的加号，也不是普通笔记收藏夹。此时不用自己点进相册，程序会在导入时操作。

## 第五步：完成四张测试图验证

1. 在搬运助手点击 **“设置与帮助 → 3 首次验证”**。
2. 点击 **“自动试导四种格式”**。
3. 等待程序依次处理 GIF、JPEG、PNG、WebP 测试图。运行期间不要点击模拟器里的其他位置，也不要关闭模拟器。
4. 完成后，拿起手机，在后台应用列表中把小红书划掉，再从桌面重新打开。
5. 打开手机小红书的聊天收藏表情面板，检查四张测试图是否都出现。
6. 检查 GIF 和 WebP 测试图中的圆点是否会移动。
7. 全部正常，才点击工具中的 **“已全部同步，开始搬运”**。

四张测试图由程序自带，会真实加入你的收藏。以后不需要时，可以自己在小红书里删除。已经完成验证的格式不会每次重新测试。

**有一张不成功怎么办？** 选中对应测试图，点击“处理选中测试图”，根据实际收藏结果操作；确认未收藏后，再继续未完成的试导。如果实际已收藏但程序没得到验证证据，可按提示换一张测试图。不要直接把失败项勾成成功。

## 以后怎么从微信搬运

每次按这个顺序即可：

1. 打开电脑版微信并保持登录。
2. 打开雷电模拟器，将小红书停在 **“已添加的表情”面板**。
3. 在工具的 **“开始搬运”** 核对来源和账号，勾选确认。
4. 点 **“导入微信新增表情”**。
5. 等待读取、下载、去重和导入。首次表情多时通常比后续扫描新增慢。
6. 完成后，**在手机后台关闭小红书，再打开**，核对新增收藏及动画。

主按钮如果显示“完成首次设置”，说明还有设置或验证没完成。点击它，程序会带你去相应步骤。

想先挑选再搬运，可以先点 **“先预览表情”**。读入后到“我的表情”挑选需要的图片，再点“导入选中”。

## 怎么导入电脑文件夹里的图片

1. 在 Windows 文件资源管理器里找到你的表情图片。
2. 在工具点击 **“开始搬运 → 从文件夹添加”**。
3. 选择直接存放图片的那个文件夹。
4. 等待扫描完成，到 **“我的表情”** 查看结果。
5. 点 **“缩略图”** 可以把图片排成多列；点击图片即可选择或取消。
6. 想选剩余全部普通待处理图片，点 **“全选待导入”**。
7. 点旁边的 **“导入选中”** 开始。

**当前只扫描第一层。** 假设图片放在“我的表情\猫咪”里面，选择“我的表情”不会读到猫咪子文件夹中的图，应直接选择“猫咪”。支持 PNG、JPG/JPEG、GIF、WebP，微信数据库和加密缓存不能作为普通图片导入。

## 进度条和任务状态怎么看

使用“导入选中”时，窗口上方显示本批进度。未验证的格式会先保留，不算进当前批次。

| 状态 | 你可以怎样理解 |
| --- | --- |
| 待处理 | 还没完成导入 |
| 已收藏 | 程序核对通过，或用户已确认结果；手机同步和动画仍应实际检查 |
| 待核对 | 可能已添加，但结果需要确认 |
| 已跳过 | 当前批次先不处理，不代表一定没收藏 |
| 失败 | 本次操作没有正常完成，查看原因再处理 |
| 待重试 | 已确认未收藏，加入了异常重试队列 |

**不要为了让进度条走满，把不确定的图片全部标为已收藏。** 这些状态是以后避免重复导入的重要记录。

## 怎么暂停和继续

点击窗口右上角 **“暂停任务”**。显示“正在暂停…”时，等待当前操作结束；网络请求可能需要一点时间才能返回。

继续前，把模拟器重新停在收藏表情面板。普通待处理图片可重新选择后导入；失败、跳过和待核对图片去“异常处理”。已经确认成功的记录会保留。

## 失败或跳过的表情怎么集中处理

1. 打开工具顶部 **“异常处理”**。
2. 点击图片查看预览和完整原因；可以使用搜索或状态筛选。
3. 先在小红书实际收藏中检查有没有这张图片。
4. **已经有了：** 点“选中已收藏”。
5. **确认没有：** 点“选中未收藏，加入重试”，再点“重试选中”。
6. **不确定：** 先保留，不要重复添加。

默认的“逐张人工核对”会每张添加后暂停。手机确认同步与动画正常后，点 **“确认本张已收藏并继续”**。

选择了图片时，重试按钮只处理所选的待重试图片；没有选择时，“重试队列”会处理当前账号的全部待重试项。点击前看清按钮附近显示的张数和范围。

重试后看起来没反应时，查看 **重试按钮附近的进度或错误提示**。“用户确认未导入，重新排队”是之前的操作记录，不代表本次已经启动。

## 看见 0 张时，先看哪一项是 0

- **“微信记录读取完成：0 条”**：检查微信来源、登录账号、电脑版表情面板和具体微信版本。路径显示不等于成功读取。
- **“新导出 0 张，复用缓存很多张”**：可能正在使用之前下载过的原图，不一定有故障。
- **“新建任务 0 张，已有记录很多张”**：可能已经读取过，到“我的表情”或“异常处理”查看原任务。
- **本地图片扫描为 0**：检查是否选了图片实际所在的子文件夹，以及扩展名是否受支持。

如果仍无法判断，请复制完整提示并记下微信版本、工具版本与操作步骤，到 [Issues](https://github.com/magofficinalis/wechat-sticker-mover/issues) 反馈。截图请先遮住账号、私人聊天和个人路径，**不要上传微信数据库、密钥或整个数据目录**。

## 如何备份、换电脑和升级

1. 先关闭搬运助手。
2. 按键盘 **`Win + R`**。
3. 粘贴 `%LOCALAPPDATA%\XHSStickerImporter`，按回车。
4. 把整个目录复制到自己安全的备份位置。

其中有任务、缓存、配置和验证记录，不要只备份 EXE。`wechat-cache` 里的图片可能仍被任务引用，正在使用时不要随意删掉。

升级时先关闭旧版，再安装新版，默认会沿用本机数据目录。换电脑或更换模拟器后，连接、路径与验证环境可能变化，应重新核对并完成程序要求的首次验证；不要把原电脑的验证标记当成新电脑已经测试通过。

更多技术细节、源码运行和许可证说明见 [README](../README.md)。
