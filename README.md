# 表情搬运助手

**把自己的微信收藏表情，批量搬到小红书。**

表情搬运助手是一个 Windows 桌面工具。它可以读取电脑版微信中“我添加的表情”，下载原图，也可以直接添加电脑里的表情图片，然后通过安卓模拟器逐张加入小红书的收藏表情。

支持 **PNG、JPEG、GIF、WebP**，提供图片预览、内容去重、批次进度、暂停恢复和集中异常处理。动图按原文件搬运，不把 GIF 自动转换成静态图片。

> **先看兼容范围。** 这是依赖特定微信数据结构和小红书界面的自动化工具，不能保证所有版本、所有表情都能成功。首次使用需要完成四种格式试导，并在手机上确认同步和动画。详情见[兼容性](#兼容性)。

## 能做什么

| 功能 | 具体行为 |
| --- | --- |
| 从微信读取 | 读取选定账号的已添加表情记录，下载可取得的原图，并复用已校验的缓存 |
| 从文件夹添加 | 扫描本地 PNG、JPG/JPEG、GIF、WebP 文件；当前只扫描所选文件夹的第一层 |
| 自动逐张收藏 | 在模拟器的小红书界面中完成选择图片、确认添加和结果核对 |
| 列表 / 缩略图 | 切换详细列表与多列图片网格，两个视图共享选择 |
| 批次进度 | 使用“导入选中”时显示本批已收藏、尚未成功和异常数量 |
| 内容去重 | 按目标账号标签与文件 SHA-256 去重；同文件改名也能识别 |
| 暂停与恢复 | 保留任务结果，继续处理剩余图片；不自动重复提交结果不确定的图片 |
| 集中异常处理 | 汇总失败、已跳过、待核对和待重试图片，确认实际收藏后再决定重试 |
| 首次验证 | 自动准备 GIF、JPEG、PNG、WebP 四张测试图，完成手机同步确认后再启用相应格式 |

本项目不提供微信、小红书或模拟器账号，不处理扫码登录、验证码，也不提供第三方应用安装包。它不是微信或小红书的官方产品。

## 兼容性

| 环节 | 当前范围与验证情况 |
| --- | --- |
| 工具运行 | 面向 **64 位 Windows** 桌面环境；源码使用 Python 3.11 和 Tkinter |
| 电脑版微信 | 沿用上游对 **4.1.13.12、4.1.13.65、4.1.15.13** 的适配；本项目开发环境已实测 **4.1.15.13**，其他版本尚未验证 |
| 安卓模拟器 | 目前使用 **雷电 9** 完成适配与实测，需要开启本地 ADB 连接 |
| 模拟器内小红书 | 内置配置针对 **安卓版 9.33.4、横屏 16:9** 的收藏表情界面；其他版本或布局需要重新适配 |
| 手机 | 安卓手机、iPhone 均可用于核对同一小红书账号的收藏同步；电脑仍需为 Windows |
| macOS | **尚未发布可用的 Mac 版本**，不要把 Windows 安装包用于 Mac |

**微信版本限制影响的是直接读取微信收藏表情。** 已有图片文件时，可以使用“从文件夹添加”，无需读取微信数据库；小红书与模拟器的适配要求仍然存在。

**手机小红书不要求与模拟器版本相同。** 上表中的 9.33.4 指被程序操作的模拟器应用。首次使用、切换目标账号、设备或界面配置后，应重新按程序引导完成验证。

### 已知边界

- 微信已添加的自定义表情与商店整套表情不同；商店整套加密表情不在当前导出范围内。
- 版本变化、下载链接失效、图片损坏、网络异常或页面变化都可能导致读取或导入失败。
- 预览较大的动图时可能只显示首帧，这不会修改原文件。动图最终是否正常播放，需要在手机端实际核对。
- 去重依据是文件内容，不是“看起来相似”。重新压缩、裁剪或转换格式后的图片可能被视为新文件。
- 本工具无法识别所有以前手动加入小红书、但没有保存在本工具任务记录中的表情。
- 程序判断的是模拟器中的添加结果，不等于已经逐张验证手机同步和动画播放，也不代表成功率保证。

## 下载安装

1. 打开 [Releases](https://github.com/magofficinalis/wechat-sticker-mover/releases)，进入最新版本。
2. 在 **Assets** 中下载 Windows 安装包或发布包。GitHub 自动生成的 `Source code` 是源码，普通用户不需要下载它来安装。
3. 如果下载的是 ZIP，先右键选择 **“全部解压缩”**。不要直接在压缩包里运行程序。
4. 打开解压目录中的安装程序，按向导安装；安装后从开始菜单打开 **“表情搬运助手”**。
5. 阅读发布包中的“先看这里.html”，或继续阅读下面的首次设置步骤。

当前发布的 0.8.1 Windows 包**没有代码签名**，Windows 可能显示“未知发布者”。请核对下载来源及发布页提供的校验值；不要为了运行程序关闭系统防护。普通用户无需安装 Python。

如果使用免安装版，需保留 `StickerImporter.exe` 旁边的 `_internal` 文件夹，不能只复制一个 EXE。

### 升级与保留记录

先关闭旧版程序，再安装或解压新版。默认数据目录是 `%LOCALAPPDATA%\XHSStickerImporter`，新版会继续使用其中的任务记录与配置。建议在升级前备份整个数据目录；如果之前通过 `--data-dir` 指定过位置，升级后应继续使用相同目录。

## 第一次使用

更细的点击顺序见 **[新手操作教程](docs/QUICKSTART.md)**。第一次需要完成下列三步，之后不必每天重新设置。

### 1. 连接模拟器

安装并打开雷电 9，在模拟器设置中将 **ADB 调试** 设为 **本地连接**，保存并重启。安装小红书并自行登录，设置横屏 16:9。

在工具中打开 **“设置与帮助 → 1 连接模拟器”**，点击 **“查找模拟器”**，选择正在使用的设备。不要同时选错另一个模拟器实例。

### 2. 选择微信来源与小红书账号

保持电脑版微信已经登录。在 **“2 微信和账号”** 点击 **“查找微信”**，选择当前微信账号对应的来源；如果有多个来源，请明确选择。

找不到时，点击 **“手动选择”**，定位到：

```text
xwechat_files\你的微信账号目录\db_storage\emoticon\emoticon.db
```

这里选择的是 **`emoticon.db` 文件**，不是微信安装目录，也不是存放图片的文件夹。显示路径只说明选中了文件，并不代表已成功读取该微信版本的数据。

填写一个便于记忆的小红书账号标签，例如“我的小红书”。它只是本地任务分组名称，不是密码。核对模拟器和手机登录的是同一目标账号，然后勾选账号确认。

### 3. 完成四种格式试导

在模拟器里进入小红书聊天窗口，打开能看到添加加号的 **“已添加的表情”收藏面板**。

在工具的 **“3 首次验证”** 点击 **“自动试导四种格式”**。程序会依次添加自带的 GIF、JPEG、PNG、WebP 测试图，已验证格式不会重复测试。测试图会实际加入小红书收藏，之后可自行删除。

试导完成后：

1. 在手机后台应用列表中把小红书划掉，再从桌面重新打开。
2. 进入手机小红书的收藏表情面板，核对四张测试图是否都已同步。
3. 检查 GIF 和 WebP 测试图中的圆点是否在移动。
4. 全部正常后，点击工具中的 **“已全部同步，开始搬运”**。

如果某张测试没有完成，请先按页面提示处理该张测试，不要直接修改配置文件中的版本号或验证标记来跳过验证。

## 日常搬运

### 从微信导入新增表情

1. 登录电脑版微信，打开雷电模拟器里的小红书收藏表情面板。
2. 到工具的 **“开始搬运”** 核对微信来源和小红书账号，勾选确认。
3. 点击 **“导入微信新增表情”**。程序会读取记录、取得原图、去重，再处理本次来源中符合条件的待导入图片。
4. 导入过程中保持模拟器页面不动。需要暂停时，点击窗口右上角 **“暂停任务”**，等待当前操作收尾。
5. 完成后，在手机后台关闭并重新打开小红书，核对收藏及动画。有异常时到 **“异常处理”** 集中处理。

想先挑选图片时，点击 **“先预览表情”**，读取完成后在“我的表情”中选择。

### 从电脑文件夹添加

在 **“开始搬运 → 从文件夹添加”** 选择已经存有表情原图的目录，扫描完成后进入“我的表情”。

**当前只扫描所选文件夹的第一层，不进入子文件夹。** 如果图片放在某个子文件夹中，请直接选择那个能看到图片文件的子文件夹。微信数据库或加密缓存不是普通图片，不能靠这个入口直接导出。

## 预览与选择图片

- **列表 / 缩略图**：列表适合看状态；缩略图适合看图挑选。切换视图时选择保持同步。
- **点图片多选**：缩略图视图中再次点击可以取消选择。选中后右侧显示预览与详情；网格本身使用首帧。
- **全选待导入**：选择当前账号的普通待处理图片，不包含已收藏、失败、已跳过、待核对或异常重试队列中的项目。
- **导入选中**：只处理选中的合格图片，窗口上方显示本批进度。尚未验证的格式会单独提示并保留，不算入当前批次。
- **更多**：提供继续普通待处理队列、重新扫描上次文件夹、查看重复明细、导出结果 CSV 等操作。

“未成功”不一定是失败，也包含尚未处理或需要人工核对的项目。进度条不会把跳过项冒充为已收藏。

## 异常处理与重试

**“已跳过”“超时”“待核对”都不等于没有添加成功。** 某张图片可能已经提交，只是程序没捕捉到足够的成功证据。先核对实际收藏，才能避免重复添加。

| 实际情况 | 在“异常处理”中的操作 |
| --- | --- |
| 已经收藏并同步 | 选中图片，点击 **“选中已收藏”** |
| 确认没有收藏 | 点击 **“选中未收藏，加入重试”**，再点击 **“重试选中”** |
| 暂时无法判断 | 保留原状态，或在“更多”中选择 **“暂不重试选中”** |
| 长动图需要逐张检查 | 使用默认的 **“逐张人工核对”**；每张添加后，在手机确认，再点 **“确认本张已收藏并继续”** |

重试按钮会显示本次范围：选中待重试图片时只重试选中项；没有选择时，“重试队列”会处理当前账号的全部待重试项，不受搜索和筛选影响。首次验证测试图需回到首次验证页面继续。

0.8.1 在重试按钮附近增加了检查进度和失败原因。若看到“用户确认未导入，重新排队”，那是队列记录；应同时查看按钮附近的本次提示，不能只凭这句话判断已经开始重试。

## 常见问题

### 微信路径显示了，为什么还是 0 张？

先看完整提示，三个“0”含义不同：

| 提示位置 | 表示什么 | 下一步 |
| --- | --- | --- |
| 微信记录读取完成：0 条 | 本次读取没有得到表情记录 | 确认选择了当前登录账号的 `emoticon.db`，检查电脑微信表情面板是否有已添加表情，并记录微信具体版本 |
| 新导出 0 张 | 本次没有新下载文件 | 同时看“复用缓存”和“未取得原图”；复用缓存大于 0 时不代表读取失败 |
| 新建任务 0 张 | 没有创建新任务 | 同时看“已有记录”和任务状态；可能此前已经读取或导入过 |

未知微信版本、尚未在电脑版显示的收藏、选择了其他账号的数据库，都需要进一步核对。**仅凭“0 张”不能确定原因，本项目尚未承诺解决所有未知版本的空结果。** 反馈时请附完整提示、微信版本和操作步骤，不要上传微信数据库。

### 本地文件夹扫描为空，但单张图片能用？

确认选择的是图片实际所在目录。当前不递归扫描子文件夹，只识别 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`。详细扫描问题见数据目录中的 `scan-errors.json`。

### 模拟器里添加了，手机怎么没看到？

确认两端登录同一个小红书账号。**首次试导和正式搬运后，都需要从手机后台关闭小红书，再重新打开查看。** 重新打开后仍未同步，应保留待核对状态，先检查实际收藏结果，不要立即反复重提。

### 为什么点击导入后跳到首次验证？

当前账号、模拟器、界面配置或所选格式尚未完成验证。按提示完成对应格式试导。已经验证的格式会优先处理，尚未验证的格式保留；更换账号、设备或配置后不能直接沿用旧资格。

### 等待“已添加的表情”超时怎么办？

把模拟器返回聊天中的收藏表情面板，确保看到添加加号，并保持页面不动。检查登录状态、弹窗、横屏布局和小红书版本。若图片可能已经提交，先到异常处理核对，不要直接重试。普通超时通常不需要重新导入或编辑界面配置。

### 新用户要自己录制界面适配吗？

使用已适配的小红书 9.33.4 与横屏 16:9 布局时，首次自动试导会准备内置配置。新用户仍需连接设备和核对测试结果。其他版本或布局可查看 **“设置与帮助 → 高级选项 → 界面适配说明 / 手动记录”**；自定义配置不自动继承内置视觉核对能力。

### 为什么有重复图片？

程序按“账号标签 + 文件内容”识别重复，无法覆盖所有历史手动收藏。换账号标签、转换格式、重新压缩或裁剪会影响去重结果。请保持目标账号标签稳定，并保留任务数据库。

### 为什么第一次读取很慢？

首次需要读取记录、下载与校验较多原图。后续新增扫描会复用已校验缓存，原图下载最多并发 4 张。若缓存被删除、来源改变或链接不可用，耗时与结果会不同。

## 数据与隐私

默认数据目录：

```text
%LOCALAPPDATA%\XHSStickerImporter
```

在 Windows 中按 `Win + R`，粘贴上面的地址并回车即可打开。

| 文件或目录 | 用途 |
| --- | --- |
| `queue.sqlite3` | 任务、去重与核对记录 |
| `settings.json`、`profile.json` | 本机连接和界面配置 |
| `wechat-source.json` | 选定微信数据库的位置 |
| `wechat-cache/` | 下载的表情原文件，部分任务会继续依赖它们 |
| `trial-batch.json` | 首次验证进度 |
| `wechat-last-result.json`、`scan-*.json` | 读取、扫描及重复明细 |
| `diagnostics/` | 诊断截图及界面信息，可能含个人内容 |

微信读取只查询选定表情数据库及其日志，不查询聊天记录。读取密钥与解密数据库保留在内存中，不主动写入磁盘或日志；程序不会自动申请管理员权限。原图下载会访问微信相关 CDN，小红书同步由小红书客户端完成，不能理解为完全离线。

自动核对成功或用户确认收藏后，程序仅清理模拟器中与成功任务对应、由本工具创建的暂存副本。电脑原图、微信收藏和小红书收藏不会因这项清理被删除。异常图片会保留以便核对。

备份数据前先关闭程序，再复制整个数据目录。不要把该目录、微信数据库、缓存原图、密钥、账号信息或未脱敏的诊断截图提交到公开仓库或 Issue。

## 从源码运行

使用 Windows 和带 Tkinter 的 **Python 3.11**。以下命令在项目根目录的 PowerShell 中执行：

```powershell
git clone https://github.com/magofficinalis/wechat-sticker-mover.git
cd wechat-sticker-mover
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe launch.py
```

无需激活虚拟环境，直接调用 `.venv` 中的 Python 即可。第三方运行依赖固定在 `requirements.txt`，开发与构建依赖见 `requirements-dev.txt`。

开发测试建议指定独立数据目录，避免使用真实任务记录：

```powershell
.\.venv\Scripts\python.exe launch.py --data-dir .\local-data
```
